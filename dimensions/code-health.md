# Dimensions: Risk hotspots + Code smells & antipatterns

Risk hotspots = files where bugs are most likely to live (size × churn × complexity). Code smells & antipatterns = patterns that erode sanity over time.

## What "good" looks like

- No file in `app/` over 300 LOC; controller actions ≤25 lines.
- `rubycritic` shows mostly A/B grades; F-grades only in legacy/admin areas.
- `reek` warnings concentrated in identifiable refactor backlog, not scattered.
- Service/form-object layer follows a single calling convention (everywhere `.call` or everywhere `.perform!`).
- No `update_column` / `save(validate: false)` / `update_columns` outside well-justified spots.
- Callback chains ≤3 deep on any model.
- No deep `params` train wrecks (`a.b.c.d.e` on user input).
- No magic numbers in money/time-window code.
- Generic `rescue StandardError` only at app boundaries (controllers, jobs) — never inside services.

## Checks

### Risk hotspots — top 5 largest per layer

```bash
for layer in models controllers services forms jobs serializers mailers; do
  echo "=== $layer ==="
  find app/$layer -name "*.rb" -exec wc -l {} + 2>/dev/null | sort -rn | head -6
done
```

Cross-reference with git churn:

```bash
# Top 20 most-edited files in last 6 months
git log --since="6 months ago" --pretty=format: --name-only | grep -E "^app/" | sort | uniq -c | sort -rn | head -20
```

The intersection (large × frequently-edited) is the highest-risk set. List each.

### `reek` smells

```bash
bundle exec reek -f json app/ lib/ > tmp/rails-audit/reek.json 2>/dev/null
```

Tally smells by type. The high-value ones to surface:
- `FeatureEnvy` — methods that talk to another object's data more than their own
- `LongParameterList` (>4 args)
- `LongMethod` (>20 lines)
- `DataClump` (same parameter cluster appearing repeatedly)
- `DuplicateMethodCall` — within a method, indicates missing local var
- `IrresponsibleModule` — class without comment (low signal, ignore unless it's policy)

Top 20 worst offenders by `<file>:<line>` make the punch list.

### Rails-specific antipatterns (hardcoded checks)

#### Fat models / fat controllers

```bash
# Models > 300 LOC
find app/models -name "*.rb" -exec wc -l {} + | awk '$1 > 300 {print}' | head
# Long controller actions (heuristic: between def..end runs)
ruby -e 'Dir.glob("app/controllers/**/*.rb").each { |f| body = File.read(f); body.scan(/def (\w+).*?\n((?:[^d]|d(?!ef\b))*?)\bend\b/m) { |m| name, code = m; lines = code.lines.size; puts "#{lines} #{f}##{name}" if lines > 25 } }' 2>/dev/null | sort -rn | head
```

#### `update_column` / validation bypass

```bash
grep -rn "update_column\|update_columns\|save(validate: false)\|save!(validate: false)" app/ --include="*.rb"
```

Each → **High** unless the file is `db/seeds.rb` or a one-off rake task.

#### Callback chains

```bash
# Count callbacks per model
ruby -e 'Dir.glob("app/models/**/*.rb").each { |f| count = File.read(f).scan(/^[ \t]*(before|after|around)_(save|create|update|destroy|commit|validation)\b/).size; puts "#{count} #{f}" if count >= 5 }' 2>/dev/null | sort -rn
```

Models with ≥5 lifecycle callbacks → **Medium**. ≥8 → **High** (debugging hell).

#### Train wrecks (Law of Demeter)

```bash
grep -rnE "\.\w+\.\w+\.\w+\.\w+" app/views/ app/serializers/ --include="*.rb" --include="*.erb" 2>/dev/null | head -20
```

Concentrated in views/serializers → **Medium**. In service objects on user input → **High**.

#### Boolean flag parameters

```bash
grep -rnE "def \w+.*\b(charge|notify|send|persist|skip|force):\s*(true|false)" app/ --include="*.rb"
grep -rnE "def \w+.*\b\w+:\s*(true|false)" app/services/ --include="*.rb" | head
```

Methods like `def perform(user, charge: false, notify: false)` → split into separate methods.

#### Service-object interface inconsistency

```bash
# Find the entry method on each service
ruby -e 'Dir.glob("app/services/**/*.rb").each { |f| body = File.read(f); methods = body.scan(/^  def (\w+)/).flatten; main = (methods & %w[call perform perform! execute run]).first; puts "#{main || "?"} #{f}" }' 2>/dev/null | sort | uniq -c | sort -rn | head
```

If a project has a mix of `.call`, `.perform`, `.run`, `.execute` across services → **Medium** (pick one, document, refactor incrementally).

#### Generic rescue inside services

```bash
grep -rn "rescue StandardError\|rescue Exception\|rescue =>\|rescue$" app/services/ app/models/ --include="*.rb"
```

Generic rescue inside a service swallows real errors. Each → **Medium**. Inside a model `save` callback → **High**.

#### Strong-params escape hatches

(Cross-listed with security; if found here too, it's a smell concentration.)

```bash
grep -rn "\.permit!\|\.to_unsafe_h\|params\.except" app/controllers/ --include="*.rb"
```

#### Routes file complexity

```bash
wc -l config/routes.rb
# Nesting depth
ruby -e 'depth = 0; max = 0; File.foreach("config/routes.rb") { |l| depth += l.scan(/\bdo\b/).size; depth -= l.scan(/^\s*end\b/).size; max = depth if depth > max }; puts "max nesting: #{max}"' 2>/dev/null
```

Routes >300 lines → **Medium**. Nesting >3 deep → **Medium** (splits up controllers awkwardly).

#### Magic numbers in money/time code

```bash
# Money-shaped magic numbers
grep -rnE "[^a-zA-Z_]([0-9]{3,})\b" app/services/payments/ app/jobs/payments/ 2>/dev/null | grep -vE "Time|hours|minutes|days" | head
```

Each unexplained 3+ digit literal in payment code → **Medium**. Document with named constants.

#### Direct ActiveRecord in views/serializers

```bash
grep -rnE "\.where\(|\.find_by|\.first\(|\.last\(|\.count\b|\.exists\?" app/views/ app/serializers/ 2>/dev/null
```

Each → **Medium** (untested, breaks preloading). Concentrations → **High**.

#### Concerns-as-namespace dumps

```bash
ls app/controllers/concerns/ app/models/concerns/ 2>/dev/null
# For each concern, check that it has `extend ActiveSupport::Concern` AND state (instance methods that share data) — pure module collections of helpers should be POROs in lib/.
```

Concerns without shared state → **Low**.

#### Polymorphic / STI without index

```bash
# Polymorphic associations
grep -rn "polymorphic: true" app/models/ --include="*.rb"
# Cross-reference with index in schema
grep -A 5 "add_index.*type" db/schema.rb
```

Polymorphic association without a `[type, id]` composite index → **High** (full-table scans).

#### Counter cache opportunities

```bash
# Look for .count calls in serializers/views
grep -rnE "\.count\b|\.size\b" app/serializers/ app/views/ 2>/dev/null | head
```

`.count` in a serializer (per-record) → **High** (N queries on collection rendering).

### TODO/FIXME density

```bash
grep -rcE "TODO|FIXME|HACK|XXX" app/ --include="*.rb" | grep -v ":0" | sort -t: -k2 -rn | head
```

TODO density per file. Top offenders go in the appendix as a table; not punch-list-worthy alone unless ≥10 in one file (then **Medium**).

### Comments and dead code

```bash
# Commented-out code blocks (heuristic: # followed by code-shaped content)
grep -rnE "^[[:space:]]*# +(def |class |module |if |end |[A-Z]\w+\.)" app/ --include="*.rb" | head
```

Concentrations of commented-out code → **Medium** (likely dead). Use `debride` for actual dead-method detection.

## Cross-cuts

Code-smell findings frequently touch other dimensions. Default secondary tags:

- **`data-integrity`** — `update_column`, `save(validate: false)`, missing unique indexes are integrity-relevant.
- **`security-and-authz`** — smells on security columns (`is_admin`, `is_blocked`, `role`) are auth-relevant.
- **`money-and-payments`** — smells on money columns (`stripe_*`, `amount_*`, `payout_*`) are money-relevant.
- **`performance`** — fat methods, train wrecks in serializers correlate with N+1 risk.
- **`risk-hotspots`** — a smell concentrated in a large file is both a smell *and* a hotspot.

## Severity calibration

| Pattern | Default tier |
|---|---|
| `update_column` on a security-relevant column (`is_admin`, `is_blocked`, `role`) | High |
| `save(validate: false)` outside seeds/migrations | High |
| Polymorphic association without `[type, id]` composite index | High |
| `.count` in serializer rendering a collection | High |
| `.find(params[:id])` in controller without owner scoping | (cross-listed, Blocker — see security dimension) |
| Generic `rescue StandardError` in service/model | Medium |
| Model >300 LOC | Medium |
| Controller action >25 lines | Medium |
| Callback chain ≥5 | Medium |
| Service interface inconsistency | Medium |
| Train wrecks in views/serializers | Medium |
| Boolean flag parameters | Medium |
| `flog` score >60 on a method | High |
| `rubycritic` F-grade in critical path | High |
| `rubycritic` F-grade in admin/legacy | Low |
| TODO density ≥10 in one file | Medium |
| Magic numbers in payment code | Medium |
